# MCP Playground Desktop: downloads

Installers and auto-update files for [MCP Playground Desktop](https://mcpplaygroundonline.com), the desktop app for testing local stdio and localhost MCP servers.

**Download from the website:** <https://mcpplaygroundonline.com>. It picks the right file for your Mac.

Or grab a file from the [latest release](https://github.com/MCPPlayground/mcp-playground-releases/releases/latest):

- `mcp-playground-<version>-mac-arm64.dmg`: Apple Silicon (M1 and later)
- `mcp-playground-<version>-mac-x64.dmg`: Intel Macs

Windows: install from the [Microsoft Store](https://apps.microsoft.com/detail/9N3J16QJ8Q8Q).

Mac builds are signed with a Developer ID and notarized by Apple. The app updates itself from this repository. Source code is not published here.

Docs, guides and example servers: [MCPPlayground/mcp-playground-desktop-app](https://github.com/MCPPlayground/mcp-playground-desktop-app)

Support: <https://mcpplaygroundonline.com>
